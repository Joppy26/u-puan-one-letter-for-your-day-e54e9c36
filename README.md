## The entry

**Z** — zero sleep. Up all night, running on fumes, a zombie with its eyes open.

## How it works

`main.ts` writes exactly one character, `Z`, to `/output/entry.txt`. The text is
fixed and written directly — no randomness, no network, no regeneration — so
every run produces byte-identical output.

## Run

```sh
node main.ts
cat /output/entry.txt
```
